# GdzieZjem? 🍝 · Wyszukiwarka dań
> Projekt na konkurs programistyczny **„Złota Apka – Code with Calisia”**

Aplikacja rozwiązuje codzienny problem: **„Mam ochotę na konkretne danie (np. carbonara, ramen, burger, pierogi) – gdzie zjem je najbliżej i jak tam dotrzeć?”**

Wybierasz danie, podajesz adres lub miejscowość i od razu otrzymujesz listę najbliższych lokali serwujących dany posiłek.

---

## 🚀 Jak to działa?

1. **Wybór dania:** Użytkownik wybiera potrawę (np. `Carbonara`, `Pizza`, `Ramen`, `Kebab`, `Burger`, `Pierogi`, `Sushi`, `Schabowy`, `Pad Thai`).
2. **Lokalizacja i promień:** Podajesz dokładny adres lub miejscowość oraz wybierasz promień (2, 5, 10 lub 15 km).
3. **Sortowanie według odległości:** Restauracje są sortowane od najbliższej, z dokładnym dystansem w metrach i szacowanym czasem dojścia pieszo.
4. **Akcje jednym kliknięciem:**
   - 📖 **Sprawdź w Google Maps:** Bezpośredni odnośnik do karty dań, recenzji i zdjęć potrawy.
   - 🧭 **Prowadź do lokalu:** Uruchomienie nawigacji.
   - 🌐 **Strona WWW:** Przejście do oficjalnej witryny lokalu.
